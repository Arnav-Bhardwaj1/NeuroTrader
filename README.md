## 🌟 Overview & Platform Status

**NeuroTrader** is a state-of-the-art web application and backend platform combining machine learning analytics, options gamma exposure profiling, microstructural order flow analysis, stochastic Monte Carlo risk modeling, event-driven backtesting replay, global macro liquidity tracking, portfolio factor risk decomposition, SEC Form 4 insider buying cluster detection, Smart Order Routing (SOR) dark pool liquidity aggregation, and automated paper trading. Designed with futuristic dark mode glassmorphism aesthetics and micro-animations, NeuroTrader provides professional-grade tools directly in the browser.

## 🔥 Key Feature Modules (17 Full Modules)

### 1. ⚙️ NeuroExecution & Dark Pool Smart Router Studio (`/execution-lab`) — [NEW FEATURE]
An institutional Smart Order Routing (SOR), TWAP/VWAP algorithmic execution simulator, Almgren-Chriss market impact engine, and Transaction Cost Analysis (TCA) studio with 4 interactive panes:
- **Smart Order Router (SOR) & Venue Liquidity Map**: Dynamic order routing across venues (NYSE, NASDAQ, IEX, Dark Pools) showing liquidity depth, maker/taker rebate fees, and execution speeds.
- **TWAP / VWAP Algorithmic Execution Simulator**: Algorithmic trade slicer engine that splits large orders (e.g. 50,000 shares) into TWAP, VWAP, or POV (Percentage of Volume) slices to minimize market impact.
- **Almgren-Chriss Market Impact & Slippage Engine**: Market impact model calculating temporary vs permanent price impact, spread costs, and trade size sensitivity.
- **Transaction Cost Analysis (TCA) & Implementation Shortfall**: TCA report comparing fill benchmark prices (Arrival Price, Interval VWAP, Closing Price) with Implementation Shortfall (IS) scoring.

### 2. ✨ NeuroAlpha Sentiment & Institutional Event Studio (`/alpha-lab`)
An institutional event intelligence, insider trading cluster radar, Fed NLP hawkishness analyzer, and social sentiment accelerator studio with 4 interactive panes:
- **Form 4 Insider Buying Cluster Radar**: SEC Form 4 insider transaction tracker highlighting C-suite executive cluster buys, purchase volume thresholds, and historical 6-month win rates.
- **Earnings Whisper & Implied Move Volatility Engine**: Pre-earnings IV crush calculator, historical EPS/Revenue surprise vs price gap analysis, and option straddle implied move comparison.
- **FOMC & Fed Speech NLP Hawkishness Analyzer**: NLP hawkishness vs dovishness sentiment timeline on Fed transcripts, FOMC statements, and rate hike probability heatmaps.
- **Social & Retail Velocity Acceleration Radar**: Social sentiment velocity tracker (WallStreetBets, Twitter/X Finance, StockTwits) with short squeeze candidate scores and retail flow acceleration.

### 3. 🛡️ NeuroRisk & Portfolio Stress Matrix (`/risk-lab`)
A real-time risk management, Factor Exposure, and Historical Crisis Simulation laboratory with 4 interactive panes:
- **Factor Exposure & Style Tilt Matrix**: Factor decomposition across Market Beta, Momentum, Growth, Quality, Size, and Volatility factors with interactive factor tilt sliders.
- **Component VaR & Marginal Risk Attribution**: Component Value-at-Risk (CVaR) breakdown per holding, identifying assets contributing highest tail risk to overall portfolio.
- **Historical Crisis Replay & Stress Sandbox**: Stress test portfolio holdings against historical market crises (2008 GFC, 2020 COVID Flash Crash, 2022 Inflation Spike) with drawdown trajectories and loss estimates.
- **Automated Risk Shield & Circuit Breakers**: Configurable automated portfolio circuit breakers (Max Drawdown Limit, Volatility Cap, Concentration Threshold) with real-time risk alerts and auto-hedge triggers.

### 4. 🌐 NeuroMacro & Cross-Asset Yield Laboratory (`/macro-lab`)
A cross-market macroeconomic intelligence & statistical arbitrage studio with 4 interactive panes:

- **Fed Net Liquidity & Money Supply Barometer**: Federal Reserve Net Liquidity Index (Balance Sheet minus Reverse Repo minus Treasury General Account TGA) mapped against S&P 500 price action.

### 5. 🧪 NeuroQuant Backtest & Strategy Replay Laboratory (`/backtest-lab`)

## 🛠 Tech Stack

### Frontend
- **Framework**: React 19, TypeScript 5.9, Vite 8
- **Styling**: Custom CSS design system with CSS Variables, dark glassmorphic components, custom scrollbars, and keyframe animations
- **Animations**: `framer-motion` for fluid page transitions, modal overlays, and layout layoutId animations
- **Routing**: `react-router-dom` v7
- **Data Visualization**: `recharts` for quantitative area/bar/line charts & `lightweight-charts` for interactive financial candlesticks
- **Icons**: `lucide-react`

### Backend
- **Runtime**: Node.js & Express (TypeScript)
- **Database / ORM**: Prisma ORM with SQLite / PostgreSQL support
- **Services**: Quantitative simulation services, order flow engines, execution engines, alpha lab engines, risk lab engines, macro lab engines, mock AI generation modules, and REST API controllers

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js**: v18.x or higher
- **npm**: v9.x or higher

### 2. Installation

Clone the repository and install dependencies for both frontend and backend:

```bash
# Install frontend dependencies
npm install

# Install backend dependencies
cd server
npm install
cd ..
```

### 3. Running the Application

#### Start Frontend Development Server:
```bash
npm run dev
```
Navigate to `http://localhost:5173` to explore NeuroTrader.

#### Start Backend Express API Server:
```bash
cd server
npm run dev
```
Backend API will be running on `http://localhost:5000/api`.

### 4. Build & Linting

```bash
# Type check and build frontend production bundle
npm run build

# Run ESLint check across codebase
npm run lint
```
